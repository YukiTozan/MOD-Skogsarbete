MOD v3

Hlavní menu je součástí hero a při scrollování odjede spolu s fotografií.
Na mobilu hamburger otevře menu uvnitř hero, takže nepřekryje další sekce.
Po odscrollování hero se objeví kompaktní navigace. Hamburger v ní vrátí uživatele do hero a otevře menu tam.
Texty jsou v content/cs.json a content/sv.json.
Spouštění přes VS Code Live Server nebo `python3 -m http.server 8000`.
